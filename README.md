# Platypal AI

## Overview

CareBridge AI is an AI-powered post-discharge care platform that helps patients understand and follow hospital discharge instructions while keeping healthcare staff and family caregivers informed.

## Problem

Many patients leave the hospital confused about medications, appointments, and recovery steps, leading to missed treatments, complications, and preventable readmissions.

## Solution

CareBridge AI transforms discharge paperwork into clear, personalized recovery plans and creates a communication bridge between healthcare staff, patients, and caregivers.

## Features

### 🏥 Staff Portal
- Upload discharge papers and generate AI-powered summaries
- Review, edit, approve, and send instructions
- Monitor patients through a severity-prioritized dashboard
- Respond to patient reports with:
  - Reviewed
  - Calling Patient
  - Advise ER
- Receive alerts for:
  - Missed medications (2+ days)
  - Urgent reports
  - Concerning check-ins
  - No activity for 48+ hours

### 👤 Patient Portal
- View approved instructions in their preferred language
- Listen using text-to-speech
- Track recovery with a simple checklist
- Report problems using:
  - Text
  - Photos
  - Voice
- Invite family members with customizable permissions

### 👨‍👩‍👧 Family Portal
- Join using an invite code
- View information approved by the patient
- Receive alerts and staff updates
- Submit reports on the patient's behalf

## AI Features
- Extracts information from discharge documents
- Simplifies medical terminology
- Translates instructions into multiple languages
- Assesses report severity
- Prioritizes cases for healthcare staff

## Tech Stack
- Frontend: React / Next.js
- Backend: Node.js
- Database: Firebase
- AI: OpenAI API
- Authentication: Firebase Auth

## Goal

Reduce patient confusion after discharge, improve medication adherence, and help healthcare providers identify complications earlier through AI-assisted monitoring and communication.
